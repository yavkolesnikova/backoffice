# Интерактивный прототип «Бэкофис.Контакт.ИИ»: общий вид и список клиентов

Дата: 2026-10-01

## Цель

Кликабельный прототип бэкофиса для менеджера. Показывает общий каркас страницы и вкладку «Список клиентов» со сценарием подключения услуги CRM S2. Визуал берётся из макетов (6 скриншотов). Вкладка «Журнал действий» в этот этап не входит.

## Технические рамки

- Без сборки: `index.html`, `styles.css`, `app.js` (интерфейс) и `logic.js` (поиск, проверка полей, данные). Открывается двойным кликом в браузере.
- Сервера нет. Данные моковые, хранятся в памяти; обновление страницы возвращает исходное состояние.
- Шрифт: Golos Text (Google Fonts) как замена фирменному, запасной системный без засечек.

## Каркас страницы

- Шапка: логотип-текст «Бэкофис.Контакт.ИИ»; вкладки «Список клиентов» и «Журнал действий»; справа переключатель темы и кнопка профиля.
- Активная вкладка выделена жирным и жёлтой полосой снизу.
- «Журнал действий» переключается, внутри заглушка «Раздел в разработке».
- Тема только светлая, по макету. Значок переключателя темы и кнопка профиля отрисованы, но без действия.

## Список клиентов

Заголовок «Список клиентов», строка поиска, таблица в рамке со скруглением.

Колонки: Название, Основной номер, ID, Наличие ОАТС, CRM S2.

- Наличие ОАТС: зелёный круг с галочкой или красный круг с крестиком.
- CRM S2 принимает одно из состояний:

| Состояние | Вид | Действие |
|---|---|---|
| Недоступно | `—` | нет |
| Можно подключить | синяя ссылка «Подключить» | открывает панель |
| Идёт подключение | синий бейдж «Подключение» | нет |
| Подключено | зелёный бейдж «Подключено» | нет |
| Ошибка | красный бейдж «Ошибка подключения» + ссылка «Повторить» со значком | повторная заявка |

### Правило доступности

Менеджер может подключить CRM S2 из бэкофиса только клиенту без ОАТС. У клиента с ОАТС колонка только отображает: `—`, если услуги нет, или «Подключено», если клиент сам подключил её в другом личном кабинете. Ссылок «Подключить» и «Повторить» у клиента с ОАТС не бывает.

## Сценарий подключения CRM S2

1. Менеджер нажимает «Подключить» в строке клиента.
2. Справа выезжает панель, остальная страница затемняется.
3. Менеджер заполняет четыре поля; кнопка «Подключить» становится активной.
4. Нажатие «Подключить»: панель закрывается, внизу по центру тост «Запрос на подключение CRM S2 отправлен» (4 секунды), в строке бейдж «Подключение».
5. Через ~3 секунды бейдж меняется согласно исходу, заданному для клиента:
   - «Звезда»: «Подключено».
   - «Вектор»: «Ошибка подключения» и ссылка «Повторить». При наведении на бейдж (или фокусе с клавиатуры) под ним подсказка с текстом ошибки: `ER015 SOC allready present`.
6. «Повторить» отправляет заявку сразу, без панели, с ранее введёнными данными: тот же тост «Запрос на подключение CRM S2 отправлен», бейдж «Подключение», через ~3 секунды «Подключено».

## Панель «Подключение CRM S2»

Только для чтения: Клиент, ID, Основной номер. У основного номера значок `i`. Подсказка открывается по клику на значок (не по наведению), закрывается повторным кликом, кликом вне значка или Esc (Esc закрывает только подсказку, панель остаётся). Текст:

> Номер, на который зарегистрирован клиент в Контакт.ИИ. Он будет использоваться для входа в CRM S2 по Mobile ID.

Закрытие: крестик, «Отменить», клик по затемнению, Esc. Введённые данные при закрытии не сохраняются.

### Поля ввода

Все поля с плавающей подписью: пока поле пустое и не в фокусе, подпись стоит на месте значения; при фокусе или заполнении уезжает вверх мелким шрифтом.

| Поле | Ввод | Правило | Текст ошибки |
|---|---|---|---|
| Тарифный план | выпадающий список | выбран один пункт | «Выберите тарифный план» |
| BAN (балансовый счёт) | только цифры, не больше 9 | ровно 9 цифр | «Введите 9 цифр» |
| Тарификационный номер | маска `906 644-28-95` | ровно 10 цифр | «Введите номер полностью» |
| Контактная почта | текст | формат `имя@домен.зона` | «Проверьте адрес почты» |

- Нецифровые символы в BAN и номере не вводятся. При вставке номера с `+7` или `8` в начале (11 цифр) префикс отбрасывается.
- Ошибка показывается после ухода из поля: красная рамка и текст под полем. Исчезает, как только значение становится корректным.
- Кнопка «Подключить» неактивна (бледно-жёлтая), пока не корректны все четыре поля.

### Тарифные планы

Названия условные, до появления настоящих.

| Название | Пояснение в списке |
|---|---|
| Старт | до 5 пользователей |
| Бизнес | до 25 пользователей |
| Профи | до 100 пользователей |
| Корпоративный | без ограничений |

Список открывается под полем, стрелка разворачивается. Выбор закрывает список и подставляет название в поле. Закрытие без выбора: клик вне списка или Esc (Esc при открытом списке закрывает только список, не панель). Управление с клавиатуры: стрелки, Enter.

## Поиск

Подсказка в поле: «Поиск по названию, номеру или ID».

- Фильтрация на каждое изменение запроса, без кнопки.
- Запрос сравнивается с тремя полями; строка показывается при совпадении хотя бы с одним.
- Название: по подстроке, без учёта регистра, `ё` = `е`, кавычки и лишние пробелы игнорируются. `ромашка`, `ооо ромашка`, `"Ромашка"` дают один результат.
- Основной номер: сравниваются только цифры. Из запроса убираются пробелы, дефисы, скобки, `+`; если после этого цифр 11 и первая `7` или `8`, она отбрасывается. Сравнение по подстроке. Работает только если запрос целиком состоит из цифр, пробелов, дефисов, скобок и `+`: иначе фрагмент ID вроде `a2` находил бы клиентов по случайной цифре в номере.
- ID: по подстроке, без учёта регистра.
- Пробелы по краям запроса отбрасываются; пустой запрос показывает всех.
- При непустом запросе в поле справа появляется крестик очистки.
- Совпадений нет: вместо строк текст «Ничего не найдено» и ссылка «Сбросить поиск».
- Фильтр влияет только на отображение. Состояние CRM S2 и идущее подключение у скрытых строк сохраняются.

## Журнал действий

Добавлен вторым этапом по макетам (страница и два состояния выбора периода). Код: `journal.js` (интерфейс), `journal-logic.js` (данные, фильтры, даты).

- Таблица: Сотрудник (логин), Время события (`дд.мм.гггг чч:мм:сс`), Действие, Источник. Сортировка от новых к старым.
- Пагинация: строка под таблицей показывается, только если найденных событий больше 10. В ней «Показывать: 10 / 25 / 50», счётчик вида «1-10 из 22» и кнопки «в начало», «назад», «вперёд», «в конец»; недоступные кнопки бледные. Любое изменение фильтра или размера страницы возвращает на первую страницу.
- Данные: 90 вымышленных событий за последний год относительно текущей даты, плотнее к сегодняшнему дню. Набор одинаков при каждом открытии в пределах одной минуты запуска.
- Действия и источники: «Создание УЗ S2» всегда из «Бэкофис», «Вход в кабинет S2» всегда из «S2».
- Фильтры работают совместно (по «И»): период, действие, источник, сотрудник.
  - «Действие» и «Источник»: выпадающие списки с пунктом «Все».
  - «Поиск по сотруднику»: подстрока логина без учёта регистра, на каждый ввод, с крестиком очистки.
  - Пусто: «Ничего не найдено» и «Сбросить фильтры» (возвращает период по умолчанию и очищает остальное).
- Период по умолчанию: «Последние 30 дней».
- Выбор периода открывается по клику на поле «Время события», закрывается кликом вне или Esc без применения.
  - Вкладка «Предустановленный»: Сегодня, Вчера, Последние 7 дней, Последние 30 дней, Последние 3 месяца, Полгода, Год; под названием даты периода. Клик применяет сразу и закрывает окно. Активный пункт подсвечен.
  - Вкладка «Интервал дат»: два соседних месяца, стрелки листают по месяцу. Первый клик задаёт начало, второй — конец (клик раньше начала меняет их местами), третий начинает выбор заново. Поля «Часы» с маской `чч:мм`; пустое поле означает 00:00 для начала и 23:59 для конца. Неверное время (например `25`) подсвечивается красным и не даёт сохранить. «Сохранить» применяет период; при одном выбранном дне период равен этому дню.
  - Окно открывается на вкладке, которой задан текущий период.
- Связи с вкладкой клиентов нет: подключение CRM S2 не добавляет запись в журнал.

## Вне этапа

- Тёмная тема.
- Меню профиля, авторизация.
- Сортировка, пагинация, адаптация под мобильные экраны.
- Сохранение состояния между обновлениями страницы.

## Проверка

Логика поиска и проверки полей покрыта автотестами (`node --test tests/logic.test.js`). Интерфейс проверяется вручную в браузере:

- оба сценария подключения проходят до конца, тексты тостов и бейджей совпадают с описанными;
- у клиентов с ОАТС нет ссылок действий;
- каждое поле отклоняет некорректное значение и показывает свою ошибку; кнопка активна только при четырёх корректных полях;
- поиск находит клиента по названию, номеру в разных форматах и фрагменту ID; пустой результат и сброс работают;
- в консоли браузера нет ошибок.
